# Тюльпаномания — колода событий

Замена карт событий для настольной игры «Тюльпаномания»: подготовка колоды по правилам, лента сыгранного и история партий. Работает без интернета.

## Что в папке

| Файл | Зачем |
|---|---|
| `index.html` | всё приложение: разметка, стили, код |
| `manifest.webmanifest` | название, иконки, полноэкранный режим |
| `sw.js` | service worker: кэширует приложение и шрифты для работы без сети |
| `icons/` | иконки для Android, iPhone и вкладки браузера |

## Как выложить на GitHub Pages

1. Создайте репозиторий на GitHub, например `tulip`.
2. Загрузите в корень репозитория **содержимое** этой папки (Add file → Upload files), не саму папку.
3. Settings → Pages → Source: *Deploy from a branch*, ветка `main`, папка `/ (root)` → Save.
4. Через минуту приложение откроется по адресу `https://<ваш-логин>.github.io/tulip/`.

## Как установить на телефон

- **Android (Chrome):** откройте адрес → меню ⋮ → «Установить приложение».
- **iPhone (Safari):** откройте адрес → «Поделиться» → «На экран „Домой“».

После первого открытия приложение работает без интернета.

## Как обновлять

1. Замените файлы в репозитории.
2. В `sw.js` увеличьте версию: `const VERSION = "tulip-v2";` — старый кэш удалится сам.

Страница загружается сначала из сети, поэтому при подключённом интернете новая версия приходит сразу при следующем открытии.

## Где хранятся данные

В памяти браузера телефона (`localStorage`), под одним ключом `tulip.state`:

```json
{
  "v": 1,
  "current": "id партии на столе",
  "games": [
    {
      "id": "mfz3k2ab9c",
      "order": ["red1", "jump", "drop1", "white1", "yellow1", "drop2", "red2", "bubble", "white2", "yellow2"],
      "boxed": "drop3",
      "open": 4,
      "startedAt": 1758650000000,
      "updatedAt": 1758651200000
    }
  ]
}
```

- `order` — порядок колоды сверху вниз, фиксируется при подготовке и больше не меняется.
- `boxed` — карта, ушедшая в коробку.
- `open` — сколько карт открыто. «Открыть событие» = +1, «Назад» = −1.

Всё остальное (открытые карты, остаток, окончена ли партия, раунд взрыва) вычисляется из этих полей. Хранится до 100 последних партий. Очистка данных сайта в браузере удалит историю.
